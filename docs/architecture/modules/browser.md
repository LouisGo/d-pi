# 内置浏览器

日期：2026-09-27。深度：M3 边界设计，嵌入与 AI 操作接入待定。依据 D-12；[最终需求](../../../.scratch/product-requirements/spec.md)、[不可信内容边界](../foundation-contracts.md#5-最小权限与信任b5)。返回[模块地图](README.md)。

## 用户场景与所有权

支持本地项目预览、外部浏览和登录。应用内使用共享的持久登录环境，不按项目划分账号空间；页面与项目关联不改变该规则。Main 管浏览资源及其生命周期，Renderer 管标签页和导航展示。

浏览网页与应用特权界面分离。外部页面不获得 App preload、文件接口、会话或诊断权限；网页内容不能自行发起宿主操作。登录状态由所选浏览引擎的持久机制管理，不把 cookie/密码复制进 App SQLite。

## 开始开发前需要解决

按真实预览与登录场景选择嵌入方式，核实重定向、新窗口、下载、权限请求及包内行为；不提前把候选 API 当成已确认选型。随后设计 AI 使用当前标签页还是独立标签页、操作目标身份、取消与导航变化的反馈。此选择尚未确认，不在本轮写成默认行为。

只保存必要的标签页/布局元数据，浏览器自身存储继续由其引擎管理。关闭标签页释放资源；App 退出纳入宿主协调，不让浏览器视图的卸载逻辑接管应用退出。

## 验收场景

本地预览与外部页面可分别打开；应用重开仍保留已验证登录；切换项目不会变成独立账号环境；危险 URL 和特权调用被实际拦截；页面崩溃只影响对应浏览资源；未来 AI 操作在目标关闭/导航变化后不能继续作用于误认的页面。按实现平台记录证据，不凭 Electron 跨平台推定全部兼容。
