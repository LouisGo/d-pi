# 文件与编辑器

日期：2026-09-27。深度：M1 只读与选区；M3 编辑及 TS/JS/Node 语言服务。依据 D-06/D-07/D-10/D-25；[基础契约 §5](../foundation-contracts.md#5-最小权限与信任b5)。返回[模块地图](README.md)。

## 范围与拥有者

Main 的文件功能在授权范围内读取实际文件，返回来源、版本和内容。Renderer 的 Monaco 适配管理文件模型、选区和视图资源，不直读 Node 文件系统。工作目录及授权记录由 [Thread](threads.md)提供，实际打开文件时由文件功能复核。

磁盘是文件当前内容来源，Monaco 只读模型是带版本的显示快照。文件树和代码查看在“仅浏览”下可用，不启动项目代码、shell 或语言服务。

## 交接

| 请求 / 提供方 | 返回什么 | 使用方 |
| --- | --- | --- |
| 规范化工作目录与读取范围 / Thread | 授权内目录项或可定位失败 | 文件树、@ 文件选择 |
| 资源引用、所需版本 / 视图或其他功能 | 实际目标、内容、编码/版本、大小与覆盖信息 | Monaco、[输入](input-context.md)、[Git/Diff](changes-git.md) |
| 选区及显示版本 / Monaco | 按基础契约 §4 返回冻结文字、路径、行号与来源版本；Diff 选区保留所选侧来源 | 输入和未来 Side Chat |
| 明确左右内容 / 变化模块 | 仅负责呈现的 Monaco Diff 视图 | Git/工具证据等场景 |

Diff 组件不读取 Git、不决定基线或作者，也不决定回退操作。工作区内容已变化时，旧选区仍是捕获时内容；打开来源可提示版本变化，不把旧行号冒充最新位置。

## 生命周期与失败

Monaco 模型由编辑适配按已打开资源管理并及时释放；视图卸载不删除宿主数据。异步读取绑定资源和版本，切换文件后迟到结果不能覆盖当前文件。

读取时规范化路径、解析 symlink 并检查实际目标和句柄；模型输出路径不授权访问。额外读取授权经显式文件选择/拖入，完全访问设置不授予项目执行信任。

缺失、权限失败、二进制、编码不可解和过大内容分别表达；空文件必须是真实空文件。截断有覆盖标识，不能把截断片段当完整引用或完整 Diff 基线。

## 第一批交付与验证

M1：文件树、Monaco 只读打开、选区附加、复用 Diff 呈现。验证开发态及 macOS 包内 worker 资源可用，再验收真实选择和焦点。

样本覆盖：正常文件/空文件、移动删除、外部修改、非 Git 项目、二进制/大文件、symlink 越界、读取中切文件；“仅浏览”路径无项目代码执行。选择引用的文字/行号/版本应与实际捕获一致；同路径的 Diff 左右内容不同、工作区随后变化时，恢复草稿和发送仍使用原选区及其来源。

M3 再设计编辑缓冲、保存冲突、撤销与语言服务进程归属。首批语言重点 TS/JS/Node，复用成熟机制；文件写入和语言服务的权限须按新能力落实，不能由首版额外读取授权推导。无需现在设计完整 IDE 扩展/调试体系。
