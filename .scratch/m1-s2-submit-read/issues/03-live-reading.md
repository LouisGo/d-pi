## 目标与依据

用户能看到原生文字、代码和必要工具状态，关窗重开后接回当前投影；交付无头阅读投影及正式阅读组件，以受控事件流验证，不等待发送 GUI。

受影响决定：D-21/22/26/28–32/35。共同依据：[S2 spec](../spec.md)、[确认方案](../acceptance-decision.md)、[固定版本证据](../evidence.md)、[基础契约](../../../docs/architecture/foundation-contracts.md)。授权与用户试用状态以 spec 为准；历史拆票阶段未实现；当前工程状态见下方 Answer。

## 交付与所有权

- Host 拥有有界投影和 seq/watermark；Renderer 先订阅缓冲、再快照、再接增量。缺号重同步，旧代次丢弃，不堵 stdout。
- 文字按块合并，工具/待交互/终态前刷新。超预算展示真实缺口；不建立第二份权威原生历史。
- Streamdown + Shiki 展示 Markdown/代码与工具来源、错误、截断；可选择复制，模型内容/URL 不获得执行权。
- 调用确认、执行中、待交互、失败与结束分开。无逐提交身份的流只关联会话；不凭正文匹配收据，不静默回答交互。
- Renderer 释放监听不结束 OMP；新窗口恢复投影。活动退出接入 01 的保护，不把草稿保存成功当可销毁任务。
- 复用 token、主题/密度、Base UI 与 Icon Layer；本票不做队列管理或文件/Diff 面板。

## 验收

功能和修复遵循 TDD，先目标失败测试、最小实现、再必要重构；既有正确行为补测不伪称历史红灯。实现前读取适用的 headless-features / TypeScript skill，GUI 另读设计系统 skill。

- A7：流/快照交错、重复/缺号、旧代次、缓冲溢出与终态刷新；观察输出与可见缺口，不测内部字段。
- A8 显示边界与 A11 选择/复制、流式期间输入不受阻；组件自动测试与必要 GUI 证据分开记录。
- 受控真实 RPC 事件集成验证窗口重连；完整两轮真实产品路径由 05/06 验证。

## 边界与完成

不扩大 S3 控制/恢复、S4 文件/Diff 或 M2 认证/附件/多 Thread；不修改官方 OMP。按风险验证并记录实际结果，无头通过不代表 GUI 或用户认可。阻塞票须 resolved 后开始依赖工作；未知工程细节按现有证据收敛，重要新产品取舍才对齐用户。
