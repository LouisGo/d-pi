实验使用临时隔离配置、目录及可控样本，不读取个人凭据或改用户项目。真实账户/模型的验收按届时授权记录，与确定性样本结果分开。若只有修改 Runtime 所有权、长期 fork、改变平台或功能承诺才能通过，带证据对齐；普通局部实现问题自行处理。

## 基建只做当前链路需要的部分

- 单应用工程，沿用 Electron / React / TS / electron-vite / pnpm；按实际切片创建 Main、Host、preload、Renderer 及窄共享合同，不先建 monorepo、DI、事件总线或通用 Manager。
- 从首条真实边界建立严格 TS 检查、Biome、版本化 DTO 与 Zod v4 解析；内部规则以判别联合和 ts-pattern 组织。供应商类型留在适配层，不在每个函数重复校验已可信数据。
- SQLite 先承载 Thread、草稿和提交需要的结构，迁移与恢复随第一份数据交付；不先铺远期业务表、完整 ORM 平台或文件快照库。
- 诊断从首条链路贯穿实际进程，沿用[现有预算和错误归属](../../docs/architecture/diagnostics.md)。日志设施失败与业务存储失败分开：前者不能阻塞任务，后者影响持久提交时必须停止推进。
- UI 只建立当前切片需要的布局、自有组件、Base UI 和 Hugeicons 接入。Tiptap/Monaco/Streamdown 按功能加入，不先建完整组件库或高保真原型。
- 最小包内运行尽早检查资源/ABI；正式 M1/M2 GUI 与性能验收在对应阶段完成。沿用[随包实验](../../docs/validation/packaged-runtime-evidence.md)的经验，不把旧实验版本当成全部新依赖的锁定值。

## 最近的实施切片

以下是交付顺序与真实依赖，不是已经开始的任务。后续获得开发授权后，按[本地任务约定](../../docs/agents/issue-tracker.md)细化当前切片即可，无需提前拆远期票。每个切片内部按验证 → 无头功能 → 正式 GUI 推进；相关 G1 可先行解决，不要求全表通过才写第一条链路。

| 切片 | 用户可验证的结果 | 涉及模块与必要前置 | 出门条件 |
| --- | --- | --- | --- |
| S1 项目与持久输入起点 | 打开目录、默认仅浏览、创建 Thread、保存并恢复文字草稿 | Thread、配置摘要、存储、输入；建立必需工程/诊断，验证持久化与最小 IME | 重开身份/草稿不变，未信任项目无代码执行，保存失败可见 |
| S2 一次真实提交和阅读 | 已有可用配置下允许执行，提交文字并读到真实结果 | S1；宿主、执行、阅读；提交接受与流式适配的 G1 | 收据先于派发，接受与执行结果分清，真实链路可追踪；无头与 GUI 各有证据 |
| S3 控制、窗口与故障恢复 | 回答交互、排队、干预、停止，关窗重开并继续 | S2；停止、忙碌历史、占用/恢复 G1 | 未知提交不重发，旧代次不串状态，待答/队列/后台活动参与退出判断 |
| S4 文件、选区与可信 Diff | 只读代码，附加选区，查看 Git 当前变化和工具证据 | 文件/Git 读取可与前述切片独立准备；选区接 S1/S2，工具证据接 S2 | 正常/非 Git/缺失/并发变化的来源准确，Monaco worker 和真实选择通过 |
| S5 M1 组合验收 | 一条打开项目 → 提交 → 交互 → 看文件/Diff → 继续/恢复的可用流程 | S1–S4 集成；最小 macOS 包与当前负载 | 下列 M1 场景通过，提交真实 GUI/故障证据；M2 未覆盖项明确保留 |

S5 的包内 smoke 用来尽早发现接入问题，不替代 M2 的 V1-10 完整首版交付质量验收。M1 不要求多任务 UI、全部附件和新增认证都完成，数据身份与状态不能因此退回一次性原型。

## 跨模块验收场景

这些是将来验证行为的样本，不是要求现在编写测试框架；实现时选择能发现实际错误的最小测试。公共性能数值集中在[基础契约 §7](../../docs/architecture/foundation-contracts.md#7-诊断与性能验收预算b6)，本次不新增未测预算。

| 场景 | 必须观察到的结果 | 主负责 / 协作 | 阶段与证据方式 |
| --- | --- | --- | --- |
| A1 正常提交、回答、继续 | 原生真实执行；收据、显示与草稿版本一致 | 执行 / 输入、宿主、阅读 | M1：真实 OMP + GUI |
| A2 派发前存储失败 | 未写 OMP，草稿/内容可恢复，具体阶段可查 | 存储 / 执行、输入 | M1：故障样本 + GUI 反馈 |
| A3 写出后断链或接受收据写失败 | unknown，不自动重发；重启仍保留原内容 | 执行 / 宿主、存储 | M1：可控断链/崩溃 + 重启 |
| A4 提交中继续编辑，迟到成功或错误 | 原提交得到正确结果，新草稿不被清空或覆盖 | 输入 / 执行、存储 | M1：时序样本 + 真实输入 |
| A5 停止时有队列/干预/待答 | 区分请求中断、当前执行结果和残留活动 | 执行 / 宿主、阅读 | M1：原生组合场景 + GUI |
| A6 窗口关开、Host/OMP 分别故障 | 关窗继续；故障范围正确；旧连接不污染；恢复不重放输入 | 宿主 / Thread、执行、阅读 | M1：真实进程与窗口 |
| A7 重连恰遇增量、分页 busy/缺口 | 快照水位衔接，没有伪造完整历史或空历史 | 阅读 / 宿主、存储 | M1：确定事件样本 + 忙碌原生读取 |
| A8 仅浏览、symlink 越界、目录移动或占用不明 | 不执行项目代码；不越权读取、不换目录执行、不强占会话 | Thread / 文件、配置、宿主、Git | M1：隔离项目与文件样本 |
| A9 用户和 Agent 混合修改、工具无前文 | Git 与工具来源分明；不归错作者、不伪造工具 Diff | 变化 / 文件、阅读 | M1：可控 Git 项目 + GUI |
| A10 多 Thread 并行及切换 | 草稿、提交、投影隔离；共享目录明确说明 | Thread / 输入、执行、阅读 | M1：身份与迟到结果的无头样本；M2：真实并行 GUI |
| A11 认证取消/旧配置变化、附件失败/模态丢失 | 不覆盖原配置、不静默删输入或丢图，未通过组合不标支持 | 配置、输入 / 宿主、存储 | M2：隔离样本 + 授权的真实路径 |
| A12 长输出、中文 IME、日志慢写/磁盘满 | 输入/阅读可用，缓存有界；诊断退化不改业务结果，业务落盘失败不误发 | 各操作拥有者 / 诊断设施 | M1 当前链路先测；M2 完整固定负载、对照性能及 macOS 包 |
