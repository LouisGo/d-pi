# 选择组件专项优化

日期：2026-10-07。授权：用户本轮三点组件优化请求及两张参考图。本地实施与交付，不涉及供应商请求或远端发布。

- Select 默认 bottom，关闭选中项与触发器重叠对齐；空间不足才翻转，沿用 Base UI 碰撞处理和 Portal。
- ChoiceGroup 为两个明确值的文本胶囊，选中项柔和底色、未选中项辅助文字；保留 radio 语义、方向键和 focus-visible。公开 options 改为二元 tuple，三项主题改用 Select，发送快捷键改用 ChoiceGroup。
- Select 按需支持弹层内搜索输入、可滚动选项与无结果反馈；主模型及子 Agent 模型接入，保留不可用模型和原因、显式 Apply、真实 OMP 能力与不确定状态。
- 所有现存原生 select 消费公共 Select：思考等级、子 Agent、历史、诊断。非选择型的工具菜单/状态 Popover 的专用锚定方向不受此要求影响。
- 模型目录在内存中进行搜索，不截断到前200项；未新增后台请求或依赖。失效的思考等级保持等待显式重选，不允许控件同步自动换值。
- 设计沿用 D-31/D-32，共享 token、light/dark、唯一紧凑布局。执行、存储、认证和恢复政策不变。

验收：下方/边缘弹层不覆盖触发器、窄窗不溢出；搜索输入不改变选择，禁用项不可选，键盘选择和 Esc 焦点；主题与快捷键保存；模型能力变化仍阻止无效 Apply；诊断筛选仍通过 form 提交，不在编辑中请求。

工程与试用证据见 validation.md；用户认可待反馈。
