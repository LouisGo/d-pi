# S3 试用交接

2026-09-28，版本 `0.1.0-s3.0`。用户确认官方 SDK 薄宿主路线后完成本轮 S3 工程；已交付待用户试用，不代表体验认可。仅本地提交，不推送，不进入 S4/M2。

## 已交付

- 固定未修改的 OMP SDK `18.3.0`、Bun `1.3.14` 随包运行。App 薄宿主注册原生消费前/模型调用前钩子，其余命令与扩展 UI 复用官方 RPC driver。原生队列由 OMP 持有，没有 App 自动续发队列。
- 忙碌普通发送进入 follow-up，独立“干预当前执行”使用 steer。停止中断当前执行、保留并暂缓原生队列；重复停止幂等；较新的停止使尚未处理的继续失效。明确继续才解锁，并通过公开 SDK 调度恢复同一会话的原生条目。
- confirm/select/input/editor 的当前请求可回答或取消；当前连接代次、信任、目录及选项在宿主复核。重复回答、过期、原生取消、旧代次和断链有保守状态，不自动重答。“已写出”不代表任务完成。刷新可重新订阅待答快照。
- 退出有等待、请求停止、取消；队列、待交互、后台任务、异步唤醒、已准入提交或未知状态仍存在时保留进程。停止不会清队列，因此“停止后退出”可能继续等待用户处理队列。关窗/刷新不结束 Runtime。
- unknown 保留冻结原文；明确确认再次发送使用新 submissionId 并关联原提交，可能重复的提醒在操作前展示，不消费当前新草稿。现有会话无法证明执行全周期单写时只读，不强占、不偷偷新建替代。

## 启动

在仓库根目录运行，使用新的 App 数据目录：

```sh
D_PI_DATA_DIR="$HOME/Library/Application Support/d-pi-s3-trial" \
  ./dist/s3-candidate/mac-arm64/d-pi.app/Contents/MacOS/d-pi
```

开发方式：

```sh
pnpm install --frozen-lockfile
pnpm runtime:sdk
pnpm dev
```

`D_PI_DATA_DIR` 只隔离 App 数据，不隔离 OMP 配置。沿用启动环境中的原生配置或明确设置 `PI_CODING_AGENT_DIR` / `OMP_PROFILE`。profile 通过官方规则校验，无效值不会静默回退默认配置。应用不复制凭据，不通过 shell 补环境；允许项目执行仍使用当前系统用户权限，不是沙箱。

候选包 `dist/s3-candidate/mac-arm64/d-pi.app` 为未签名 macOS arm64 应用，约 1.3 GB。SDK 完整依赖保留原许可证；旧 S2 官方 CLI 资源在工作区保留，S3 包只携带 SDK 运行资源。没有覆盖 S1/S2 候选包。

## 建议试用顺序

1. 选择可执行的测试项目，允许执行并启动 OMP；发送首条任务。忙碌时普通发送第二条，核对原生队列；需要打断方向时使用独立干预按钮。
2. 点击“停止并暂缓队列”，核对后续条目仍在且不自动消费。刷新或关窗再打开，核对仍暂停；“明确继续”后恢复同一会话。
3. 触发已有扩展的 confirm/select/input/editor，核对内容、取消和回答；试切主题、密度及真实中文输入法。自动测试已使用隔离扩展证明四类回答到达官方扩展，个人扩展仍待试用。
4. 有工作时退出，试等待/停止/取消。残留队列不会被丢弃；要退出可取消退出、继续并等待队列处理完成。应用完全退出后旧 Thread 当前只能读历史；新一轮执行需另建 Thread，不是旧会话恢复。
5. 遇到结果未知先核对原文和历史；当前仍存活且有执行资格时，可明确确认再次发送。中断后的旧绑定不会被再次发送操作绕过恢复门槛。

## 验证与限制

验证详情见 [evidence.md](evidence.md)。类型、Biome、设计 lint/边界、92 项单元/集成测试通过；1 项旧 CLI 可选 smoke 默认跳过。真实 SDK 本地模型 fixture、真实 Electron 主链路/原生扩展交互、候选包迁移到带空格路径的双轮/历史及正常退出均有本轮证据。

真实供应商认证/费用、用户配置、原生中文候选窗手感、Windows/Linux、签名公证、干净机器安装未验收。没有做 S4、完整队列编辑/删除/重排或 M2 长输出/性能验收。自动检查不是用户认可。

恢复限制是固定官方文件实现的技术门槛：发布锁只覆盖写入，未提供外部 CLI 同样遵守的执行全周期单写协议。App 自建锁、PID 扫描或关闭外部 CLI 不能替代该证明；旧 S2 的“等 S3 即可恢复”描述已被此结论取代。该门槛未解决前保持只读。
