# S4 工程交付与试用交接

2026-09-29，`0.1.0-s4.0`。S4 源码、自动化、开发态及未签名 macOS 本地包的关键 GUI 路径已完成，现交付用户试用；**用户体验尚未认可**。以 [spec](spec.md) 和 [05](issues/05-integration.md) 为后续入口。S3 仍待试用，冷恢复保持只读；S5/M2 未开启。

## 已实现

- Main 按当前 Thread 项目目录只读列目录、读取完整 UTF-8 文本；实际目标、句柄与读前后版本复核，越界 symlink、缺失、二进制、超限、变化中分别返回原因。当前文件查看上限 5 MiB，目录最多展示 500 项；不运行项目代码。
- Renderer 只读 Monaco 文件与双侧 Diff 视图，模型随视图释放。文件/左右 Diff 选区按显示文本的 UTF-16 行列、路径、来源、版本冻结，并作为不可拆分的 Tiptap 引用节点附入输入；持久化和发送时用带版本头的可读文字块保存原文，重载草稿时还原节点。单次选区上限 64 KiB，不截断。
- Git 查询分开 HEAD→index、index→工作区及未跟踪项。各项带仓库、HEAD、捕获时间和项目范围；单文件 Diff 两侧带明确来源和全文版本。未跟踪遵循 Git 忽略规则。Git 缺失、非 Git、无 HEAD、二进制、冲突、symlink/子模块、超限及采样中变化均有明确状态；文本相同的重命名/权限变化另作说明。没有暂存、回退或其他 Git 写动作。
- 重命名 Diff 的左侧选区保留旧路径，右侧保留新路径；两侧引用均带实际显示内容的版本。
- 已有关联的原生 v3 会话记录可显示工具结果的 `toolCallId`、工具名、原生记录 ID、成功/失败标记及文字部分覆盖。文件修改类工具结果有原生成功报告才显示为该类工具成功；缺可靠前后全文不绘制操作 Diff。shell、后台或工作区其他变化不自动归为 Agent。
- i18n 中英界面文案、主题/密度 token 与显式刷新已接入。原生执行信任与恢复逻辑未改变。

## 用户试用

在仓库根目录启动当前未签名本地包，隔离 App 数据：

```sh
D_PI_DATA_DIR="$HOME/Library/Application Support/d-pi-s4-trial" \
  ./dist/mac-arm64/d-pi.app/Contents/MacOS/d-pi
```

`D_PI_DATA_DIR` 只隔离 App 数据，不隔离 OMP 配置。选择一个可控项目并保持“仅浏览”；查看文件、拖选文本后点“将选区附入输入”，核对引用的路径、行列、原文与 sha256。Git 项目可分别查看 HEAD→暂存区、暂存区→工作区、未跟踪；非 Git 目录应保留文件查看并明确说明 Git 不可用。查看本地原生历史时，工具修改只在有原生记录时显示相应证据。关闭重开后可核对草稿引用保留。

试用反馈重点：文件树与代码阅读是否顺手；选区在中文、emoji 和跨行文本上是否准确；Git 两侧来源与覆盖范围是否清楚；原生工具结果是否足以判断它实际报告了什么。Agent 操作 GUI 不替代用户体验认可。

## 边界

S4 不包含 Monaco 编辑/语言服务、@ 文件、完整工具前后快照、Run Changes、逐文件作者归属或 Git 写入。Git 各侧按当前时点读取，不提供跨文件原子快照；看到的工作区差异不能据此归因于 Agent。引用在输入界面为整体节点，可整块删除或撤销；持久化的可读文字块若被外部修改而不再符合引用格式，载入时作为普通文字呈现，不冒称为原选区。
