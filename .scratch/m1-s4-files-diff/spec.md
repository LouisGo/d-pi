## 行为与所有权

Main 从当前 Thread 的目录读取，复核真实路径、文件句柄与版本；Renderer 不直读磁盘。文件树只列授权范围内项目条目；内容有大小、编码和二进制界限，缺失与读取中变化明确返回。Monaco 模型仅是显示快照，切换与卸载释放模型。选区使用所见侧的原文、行列和版本生成冻结引用，在输入中为整体原子节点；持久化与提交时序列化为带版本头的可读正文，重载时还原节点。外部文件后变不倒改引用。

Git 用只读查询区分 HEAD/index、index/工作区及未跟踪文件，记录仓库与各侧来源、采样时间和覆盖范围。每份 Diff 的两侧须实际可得；无 HEAD、冲突、二进制、超限或读取竞态不能伪装为空文件。只读查询不执行项目或用户 Git 配置提供的外部程序（生效 filter 驱动统一中和直通，采样前后复核驱动集合）；比较为去外部程序后的当前采样，不等同于完整 Git 规范化语义。Monaco Diff 默认保留首尾空白变化。特殊文件（非普通文件）在打开前即被拒绝，不占用共享文件 I/O。非 Git 项目仍可读文件与原生工具结果。原生工具结果由会话记录的 `toolCallId`、工具名和结果内容支撑；参数不等于成功，截断和原生记录缺失须明示。

## 验收

先写行为失败测试，再实现：项目内/越界 symlink、空文件/缺失/二进制/超限/并发变化；选区逐字符和行列、草稿保留；Git staged/unstaged/untracked/无 HEAD/非 Git/混合修改；原生工具 ID 与结果、缺少前文时无伪 Diff。运行类型、lint、针对性测试与构建。开发态及 macOS 包内核对 Monaco worker、真实选择、主题/密度与焦点。自动化和 Agent GUI 检查不替代用户试用。
