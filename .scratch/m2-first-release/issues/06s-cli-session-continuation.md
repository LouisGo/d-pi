## 执行归属边界

OMP 18.4.6 的原生文件锁覆盖发布操作，外部 CLI 没有共享的执行全周期协议。Main 校验当前原生配置根、canonical 原文件、header ID/cwd；为同一原文件的所有 d-pi 客户端取得文件粒度的持久生命周期 lease，沿用旧注册进程组清理与确认关闭后释放。启动前检查真实打开的写入 FD，并检查该 cwd 中存活的 OMP CLI（idle CLI 可以只保留内存而无 FD）。发现占用/未知拒绝执行但保留阅读和输入，允许同 Thread 重试，不终止外 CLI。

这支持“退出 CLI 后交给 GUI 继续”，不宣称能约束用户在 GUI 执行期间另起不遵循协议的 CLI 打开同一文件。与既有 App 私有文件的任意同 UID 外程序例外一致；不能将启动时的进程快照称为跨 CLI 的全周期锁。没有更改外部 CLI 或用户 shell。
