# M1 S1 项目与持久输入起点

日期：2026-09-27。近期实施入口；2026-09-27 用户已明确授权正式实施 S1，当前 01–05 工程交付完成，用户反馈的原文粘贴问题已修复待复试。依据[开发计划](../development-foundation/spec.md)、[基础契约](../../docs/architecture/foundation-contracts.md)、[Thread](../../docs/architecture/modules/threads.md)、[存储](../../docs/architecture/modules/app-storage.md)、[输入](../../docs/architecture/modules/input-context.md)、[设计系统](../../docs/architecture/design-system.md)。

## 用户得到什么

打开应用，选择项目目录，默认仅浏览；创建一个具有稳定身份的 Thread，编辑文字草稿；正常关闭重开应用后恢复该项目/Thread 与已保存草稿。保存失败有明确状态，仍在内存的文字不因失败被清空。首次可试用交付就包含统一主题/密度和可靠的基本输入，不用假回复演示 Agent 已运行。

## 范围与所有权

- 最小 Electron/React/TypeScript 工程、受限 preload 通道、必要构建和诊断，按既有工具路线建立。不建设远期模块骨架或全量组件库。
- Main 管项目目录准入、Thread 关联及 App 数据存储，SQLite 承载身份/草稿 revision；Renderer 的 Tiptap 管编辑正文、选择与撤销，持久化通过版本化 DTO。React 卸载不负责删除业务数据。
- 选择目录只授予约定的 App 读取范围，不执行项目配置、脚本或扩展，不暗中授予 Agent 执行信任。路径规范化及失效结果由可信宿主核实。
- 保存状态须依据持久结果；旧版本回执不把新草稿标为已保存，失败后不覆盖最新正文。常规关窗/退出协调必要保存，不能静默丢弃未落盘编辑。进程突然崩溃只能保证恢复已确认落盘版本，不承诺每次按键零丢失。
- S1 只交付一个前台 Thread 的基本流程；数据身份支持未来多 Thread，不要求完整切换、并行、删除/归档管理页。
- S1 不启动 OMP、不请求模型、不保存原生会话引用，不实现发送/队列、认证向导、附件、@ 检索、Monaco、Diff 或文件编辑。配置缺失不能阻止本地起草；配置摘要仅在本切片确有需要时以不会执行项目代码的方式读取，不提前建设 setup 服务。

## 组件与样式

按既有 Codex 式常规布局交付当前操作所需区域，不画全产品高保真页面。采用 Base UI、自有组件 API、Hugeicons Icon Layer 和最小 Tiptap；先复用[源码依据](../../docs/architecture/design-system-references.md)，不自创组件框架。

共享 token 一处定义，主题/密度集中映射；Tailwind/CSS Modules/普通 CSS 按当前可维护性选择，不按场景强制分配。S1 内确定并记录实际 token 文件入口及组件导入路径，接入 Biome、类型检查与限定设计规则的 @shadcn/lint + Oxlint；验证当前依赖兼容性，不仅安装包。

正常/compact 至少提供可测试入口，不提前做完整偏好设置页。primary 单源变更的三种样式消费者可使用最小验证样本，不要求为了测试向产品硬塞三种实现。主题/密度切换不重建输入内容或丢焦点，设计规则按正反例验证。

## 用户反馈修复

[05 Markdown原文粘贴](issues/05-markdown-source-paste.md)：S1保留剪贴板text/plain中的Markdown标记、编号、链接原文、缩进及连续空行，CRLF/CR统一为LF；存在HTML副本时不让默认HTML解析覆盖已有文字原文。此修复不承诺从HTML重建Markdown，不取代M2已确认的富内容粘贴规则，也不加入输入框所见即所得排版。

## 验收

1. 正常目录与新 Thread 关联正确；取消目录选择不产生错误关联，目录失效不自动换到别处。仅浏览没有项目代码执行。
2. 输入中文、换行、粘贴可编辑文本、光标/选区、undo/redo；真实 Electron 操作验证，不能只用合成键盘事件证明 IME 通过。
3. 正常关闭重开恢复 threadId、目录和已保存正文；保存中的新编辑、迟到回执及连续保存不丢新版本。
4. 写失败、事务中断、迁移失败可观察；失败不删库重建，不清正文，不伪报已保存。记录突然崩溃时实际恢复边界。
5. primary 源值修改和全局密度切换按设计合同传播；正反例证明 lint 识别当前组件和样式，不误禁合理 CSS。
6. 最小 macOS 包验证启动、资源、SQLite 驱动和重开；记录机器、版本、当前输入负载与响应情况，不宣称 M2 全负载或公开分发通过。
