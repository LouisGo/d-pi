## 交付与验证

使用最小临时样本或当前切片必要的开发壳，核实 Electron/Node 与 SQLite 驱动的包内兼容、事务/迁移失败；核实 Tiptap 中文 IME、选区和撤销；核实 Tailwind 与 @shadcn/lint/Oxlint 的实际版本、组件识别及 CSS Modules/变量表达的兼容。三个调查可独立开展，不先建正式页面。

隔离数据目录，不用个人配置或凭据。锁定必要版本并记录依据，不因一个候选接入困难就改已确认技术方向；若确需重大改变，带失败证据对齐。

完成证据：可重现命令、版本/平台、预期与实际、通过及缺口；设计 lint 至少有合规/违规样本，SQLite 覆盖写失败与迁移失败，输入覆盖真实 IME。仅对应证据足够时进入该实现路径。
