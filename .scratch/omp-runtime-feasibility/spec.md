# 目标

验证 OMP 18.3.0 已有能力能否由 Electron GUI 复用，确认接口缺口及适配成本，再决定后续产品化投入。不是关闭旧阶段 1 的全部验收，也不建设完整 UI。

## 范围与方法

- 重点：多会话、子 Agent 的观察与控制、跨会话记忆、模型/思考/并发相关设置。
- 兼顾：图片输入与宿主扩展入口、独立发行二进制作为随包 Runtime 的基础。
- 复用旧 Electron MessagePort/utility process、真实 GUI 开发闭环证据；只补缺失的轻量 RPC 实验。
- 固定上游 v18.3.0；隔离配置和临时项目，使用 localhost 确定性模型，不使用个人凭据、不产生真实模型费用、不安装全局 OMP。
- 区分实际实验、源码/协议事实、工程推断和未验证项；TUI 可用不直接视为 GUI 接口可用。

## 完成条件

形成可复现探针、精简机器结果和能力结论，明确可直接复用、需适配及仍有阻碍的范围。UI 美化、状态库调整、完整打包/签名、性能压测不属于本次。
