# 存量界面第一轮视觉优化

日期：2026-10-01。属于既有 M2 界面的样式升级，入口范围见 [M2 规格](../m2-first-release/spec.md)。

## 推进与交接

- 授权：用户明确要求先使用刚安装的 Impeccable 优化现有界面，完成后直接本地 commit。
- 范围：既有应用外壳、Thread 导航、配置／模型表单、运行提示、阅读区域、Composer 和空状态；沿用系统字体、Base UI、自有 Icon Layer、统一主题及 normal/compact。
- 受影响决定：D-16、D-17、D-31、D-32；保持常规桌面布局与共享视觉值单源。不改变 OMP、会话、输入、恢复或授权的业务合同，不启动完整组件库或其它未交付功能。
- 重要产品待决：无。
- 工程：样式、可复现验证和交接记录完成，与本轮源码一起本地提交。
- 用户试用：通过源码启动可试用；未生成新分发包，用户认可待反馈。
- 起点：`eaf29c9`；工作期间另一项 tooling 修正提交为 `a316af6`。本轮不纳入其源码、测试或交接变更。

## 实现

1. 在集中 token 中细化表面、侧栏、柔和选中态和 hover；深浅主题共用角色，控件与阅读文字分别设定。
2. Thread 与阅读页签复用 Button navigation 变体。选中项的副文字继承前景色，修正旧蓝底灰字的对比度。后退／前进使用有可访问名称的 Icon Layer 图标与组件 icon 尺寸。
3. 配置入口与模型控制减少重复边框，运行状态保留中性底面。输入区保留独立边界，快捷键说明与操作按钮自然换行。
4. 小窗口收紧共享留白及默认输入高度，阅读导航横向滚动；展开配置／模型使用各自的滚动预算。
5. 修正 Streamdown 的 Tailwind 扫描路径，使其段落、标题、代码块等正式样式进入构建；阅读正文限制行宽。
6. 空状态在工作区居中，继续沿用现有文案和打开项目行为。

## 验证与限制

- 真实 Electron Renderer，使用已有 rendering fixture 的隔离 bridge／合成内容；不访问个人配置或供应商，不将模拟状态称为真实 OMP 验证。
- 复现脚本：[visual-style.mjs](../../validation/m2/visual-style.mjs)。覆盖深浅主题、两种密度、中英文、只读／就绪／空状态、展开设置、键盘输入焦点及 720×540 最小窗口；断言阅读区域非零且有可用高度、输入和操作不出视口、页面无水平溢出、收起设置时运行状态可见。
- 最终十张截图与几何证据保存在 [evidence](evidence/geometry.json)，其中 [浅色工作区](evidence/ready-light-compact-zh.png)、[深色工作区](evidence/ready-dark-normal.png)、[输入焦点](evidence/editor-focus-light-compact.png)、[空状态](evidence/empty-light-normal.png) 可直接查看。常用 1000×800 就绪窗口阅读高度 271px（normal）／335px（compact）；720×540 中英文只读窗口分别保留 64px／58px，运行标题与输入操作仍可见。展开模型／配置继续使用原有可滚动设置区。
- 基础文字、辅助文字、选中态与主操作在各自背景上的对比度均至少 5.07:1；禁用态另按禁用语义呈现。
- Impeccable detector 一次扫描无报告；设计 lint、国际化 lint、Renderer 类型检查通过；`pnpm check:fast` 与 `pnpm build` 最终结果见本目录 evidence。
- 已有行为测试 500 通过，1 项既有固定 CLI opt-in 跳过；连续性 harness 的六项通过（140 个采样），覆盖主题、发送快捷键、密度、语言、Thread 和自动启动新 Thread。
- 第一次并行运行两个 Electron probe 时连续性采样数量不足；单独运行同一脚本通过，未放宽断言。展开设置的几何断言检查布局预算与输入可达，不要求被展开模型推到下方的运行信息同时出现在视口；输入焦点先通过 CDP Tab 建立键盘输入方式，再检查 `:focus-visible`。
- 尚未生成或检查新的 macOS 分发包；本轮视觉与隔离交互检查不替代真实供应商、完整输入法验收或用户认可。
